# 🌦️ WeatherWise – Temperature Prediction

## 📌 About the Project

WeatherWise is a Deep Learning mini-project developed to predict temperature using weather-related data. The project uses data preprocessing, model training, and prediction techniques to analyze weather patterns and estimate temperature values.

## 🎯 Project Objectives

- Analyze historical weather data.
- Perform data preprocessing and cleaning.
- Build a Deep Learning model for temperature prediction.
- Train and evaluate the model.
- Generate temperature predictions using the trained model.

## 🛠️ Technologies & Tools Used

- **Programming Language:** Python
- **Platform:** Google Colab
- **Deep Learning:** TensorFlow / Keras
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn

4. Upload the required dataset.
5. Install the required libraries, if necessary.
