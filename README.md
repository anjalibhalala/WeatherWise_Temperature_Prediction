# 🌦️ WeatherWise – Temperature Prediction

## 📌 About the Project
WeatherWise is a Deep Learning mini project developed to predict temperature using weather-related data. The project focuses on data preprocessing, model development, training, and temperature prediction.

## 🎯 Objectives
- Analyze weather-related data.
- Perform data preprocessing and cleaning.
- Develop a Deep Learning model for temperature prediction.
- Train and evaluate the model.
- Predict temperature using the trained model.

## 🛠️ Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 📂 Project Structure

## 🚀 How to Run the Project
1. Open the Google Colab notebook.
2. Upload the required dataset.
3. Install the required libraries, if needed.
4. Execute the notebook cells.
5. View the model results and predictions.
